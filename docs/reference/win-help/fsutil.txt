# fsutil —— 本机 fsutil.exe 的 /? 原样输出（用于参数溯源；本文件由脚本抓取，勿手工编辑）
# 命令: C:\Windows\System32\fsutil.exe /?
# 可执行文件: C:\Windows\System32\fsutil.exe
# 抓取日期: 2026-10-01
# 原始代码页/编码: oem（已按该编码解码，存为 UTF-8）
# 抓取条件: CreateNoWindow=true + 重定向 stdout/stderr + 启动后立刻关闭 stdin（与宿主一致）
# 退出码: 1   原始字节数: 792

/? 是无效参数。
---- 受支持的命令 ----

8dot3name         8dot3name 管理
behavior          控制文件系统行为
bypassIo          BypassIo 管理
clfs              CLFS 日志文件管理
dax               DAX 卷管理
devdrv            开发人员卷管理
dirty             管理卷更改位
file              文件特定命令
fsInfo            文件系统信息
hardlink          硬链接管理
objectID          对象 ID 管理
quota             配额管理
repair            自我修复管理
reparsePoint      重分析点管理
storageReserve    存储保留管理
resource          事务性资源管理器管理
sparse            稀疏文件控制
tiering           存储分层属性管理
trace             文件系统跟踪管理
transaction       事务管理
usn               USN 管理
volume            卷管理
wim               透明 wim 托管管理
