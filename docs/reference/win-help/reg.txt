# reg —— 本机 reg.exe 的 /? 原样输出（用于参数溯源；本文件由脚本抓取，勿手工编辑）
# 命令: C:\Windows\System32\reg.exe /?
# 可执行文件: C:\Windows\System32\reg.exe
# 抓取日期: 2026-10-01
# 原始代码页/编码: oem（已按该编码解码，存为 UTF-8）
# 抓取条件: CreateNoWindow=true + 重定向 stdout/stderr + 启动后立刻关闭 stdin（与宿主一致）
# 退出码: 0   原始字节数: 551

REG Operation [Parameter List]

  Operation  [ QUERY   | ADD    | DELETE  | COPY    |
               SAVE    | LOAD   | UNLOAD  | RESTORE |
               COMPARE | EXPORT | IMPORT  | FLAGS ]

返回代码: (除了 REG COMPARE)

  0 - 成功
  1 - 失败

要得到有关某个操作的帮助，请键入:

  REG Operation /?

例如:

  REG QUERY /?
  REG ADD /?
  REG DELETE /?
  REG COPY /?
  REG SAVE /?
  REG RESTORE /?
  REG LOAD /?
  REG UNLOAD /?
  REG COMPARE /?
  REG EXPORT /?
  REG IMPORT /?
  REG FLAGS /?
